# آریها — بازار آنلاین لوازم‌التحریر

یک وب‌سایت استاتیک، فارسی، RTL، mobile-first و responsive برای بازار آنلاین لوازم‌التحریر آریها.

رابط کاربری فعلی با الهام از الگوهای marketplace بزرگ مانند Alibaba.com بازطراحی شده است: سرچ اصلی برجسته، دسته‌بندی‌های سریع، کارت‌های متراکم محصول، اطلاعات فروشنده نمونه، حداقل سفارش و بخش درخواست قیمت عمده.

## ساختار

- `index.html` — صفحه اصلی marketplace
- `products.html` — کاتالوگ با جستجو و فیلتر
- `products/*.html` — صفحه مستقل هر محصول با گالری تصاویر و متادیتای اختصاصی
- `about.html` — درباره آریها
- `contact.html` — مرکز پشتیبانی و سوالات متداول
- `assets/css/styles.css` — دیزاین سیستم و استایل responsive
- `assets/js/products.js` — داده‌های نمونه محصول و فروشنده
- `assets/js/app.js` — جستجو، منو، فیلتر، گالری، سبد نمونه و تعاملات
- `robots.txt` و `sitemap.xml` — پایه SEO
- `404.html` — صفحه خطای استاتیک

## تکنولوژی

HTML + CSS + JavaScript خالص. هیچ بک‌اند، build step یا وابستگی فریم‌ورکی وجود ندارد و سایت روی هاست استاتیک معمولی قابل استقرار است.

## قبل از انتشار واقعی

1. همه آدرس‌های `https://example.com` در canonical، sitemap، structured data و Open Graph با دامنه واقعی جایگزین شوند.
2. ایمیل، شماره تماس، آدرس و ساعات کاری نمونه جایگزین شوند.
3. قیمت، موجودی، حداقل سفارش، فروشنده، امتیاز و مشخصات محصول با داده واقعی جایگزین شوند.
4. تصاویر نمونه Unsplash با تصاویر واقعی محصولات جایگزین شوند.
5. فرم تماس و درخواست قیمت عمده در صورت نیاز به بک‌اند یا سرویس خارجی متصل شوند.
6. در صورت اضافه شدن فروشنده‌های متعدد، صفحات فروشنده و مدل داده مربوط به marketplace طراحی شوند.
